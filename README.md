## 📌 Project Overview

This project was developed by following the core architecture and layout guidelines from freeCodeCamp's tutorial:
👉 [*How to Build a Simple Portfolio Website With HTML and CSS*](https://www.freecodecamp.org/news/build-a-simple-portfolio-website-with-html-and-css/) by Spruce Emmanuel.

### 🎨 Personal Touches & Customizations
- **Custom Purple Theme:** Redesigned the entire color scheme with dark purple palette tokens (`#0f0c1b`, `#2e1052`, `#a855f7`) because purple is my favorite color!
- **Interactive JavaScript:** Added dynamic interactive tilt and floating card effects inspired by [Sheryians Coding School's JavaScript Tutorial](https://www.youtube.com/watch?v=UqEmFSlx4ps).
- **Responsive CSS Grid & Flexbox:** Custom grid gallery displaying my CodeSquad project assignments side-by-side on desktop with clean mobile responsiveness.
- **Utopia Typography:** Implemented fluid typography and spacing scales using CSS `clamp()` formulas.

---

## 🛠️ Built With

- **HTML5:** Semantic layout structure (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3:** Custom properties, CSS Grid, Flexbox, Utopia fluid scaling, and keyframe animations
- **JavaScript:** DOM manipulation and visual interaction enhancements
- **GitHub Pages:** Deployment and web hosting
